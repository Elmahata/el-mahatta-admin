# إدارة المحطة — بورتال الإدارة لوحده

الفولدر ده فيه **الإدارة بس** — مفيش فيه تطبيق الراكب ولا السائق.
بيشتغل على نفس قاعدة البيانات بتاعة التطبيق، فكل حاجة بتظهر هنا أول بأول.

## الملفات
- `admin.html` — البورتال
- `index.html` — بيحوّل على البورتال علطول
- `functions/api/[[path]].js` — نفس السيرفر بتاع التطبيق (لازم يتحدّث مع كل تحديث للتطبيق)
- `assets/` — التصميم والأيقونات
- `manifest-admin.webmanifest` + `sw.js` — علشان يتثبّت كبرنامج على الماك

## الإعدادات في Cloudflare (مشروع Pages جديد)
- **D1 binding:** الاسم `DB` ← نفس قاعدة بيانات التطبيق
- **ADMIN_USER** (Text) و **ADMIN_PASS** (Secret)
